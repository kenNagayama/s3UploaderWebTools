# 開発プラン

amazon s3のバケットにオブジェクトをアップロードするための **ブラウザツール** を作ります。

- ブラウザで利用可能な単体のwebツールです。
  - ユーザの利用環境は **Windows** です。
  - Node.js は使用出来ない環境で使います。
  - html + js + css で構成します。可能であれば、1つの html ファイルで作ります。
- aws の認証情報は、 `.env` ファイルに作成します。
  - ユーザに使用例を示すため `.env.sample` ファイルを準備します。
  - テスト用の IAM ユーザの認証情報は `s3-upload-user_accessKeys.csv` にあるので、これをベースに `.env` ファイルを作ってください。
- アップロード先の `s3バケット名` と `prefix` （フォルダ）は、ブラウザ上で指定します。
  - デフォルト値としてバケット名は `twins-digital-data` 、 prefix は `tableau-access/oomiya/oomiya-mc/` にします。
    - ただし、開発中は `twins-digital-data-test` バケットを使用します。
- アップロード対象のフォルダはブラウザ上で指定します。
  - デフォルト値は `digital-data` にします。
  - `digital-data` フォルダ内に保存されている `.csv` 形式のファイルをアップロードします。
- 大容量のファイルをアップロードする可能性があるので、 **マルチパートアップロード** を有効にする必要があります。

- 開発の最初に .gitignore を作ってください。
