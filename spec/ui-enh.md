# UI改善

## 概要

基本機能ができたので、 UX設計のスペシャリストとして、ユーザーがより使いやすいように UI を改善します。

## 作業ステップ

1. ユーザーストーリーを考える
2. ユーザーストーリーに基づき、既存UIにおけるコンフリクトを整理する
3. コンフリクトを解消するためのUI改善案を考える
4. 改善案を実現することで、ユーザ体験が改善するかを内省的に考える
5. 改善案を提示する
6. （私が承認したら、）改善案を実装する

## 技術面での条件

- AWS環境へのデプロイは Github Actions で自動化されています。
  - 開発時にAWS認証情報が必要な場合は、 `auth/auth.sh` を実行して取得する
- python を使うときには **uv** を使う
- 1つのhtmlファイルにコードをまとめる（このファイルを社内で共有すれば仕事ができるようにする）

## ユーザについて

- ユーザは `電力設備技術センター(技セ)` または `電力メンテナンスセンター(メセ)` の社員
- ユーザは技セまたはメセに所属している。
- 技セのイチ組織としてメセが配置されている。
- ユーザは、自分の所属するメセの保全を行っている。自分の所属するメセまたは技セの情報は、たまに見ることがあるが、基本的にメセの保全に集中している。
