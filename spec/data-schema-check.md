# データスキーマチェック

## 概要

index.html で S3にアップロードするときに、アップロードする前に CSV のスキーマをチェックする機能を追加する。

関係ないファイルをアップロードすることを防ぎたい。

## 実装

### 1. フロントエンド

フロントエンドにCSVスキーマチェックの機能を追加する。
- ユーザーがCSVファイルを選択した際に、`FileReader` を用いて各ファイルの先頭行を Shift_JIS で読み込みます。
- 定義された期待されるヘッダースキーマ（84カラム）と一致するかを判定します。
- 一致しないファイルはアップロード対象のリストから除外し、画面上にエラー（トースト通知およびログ）を表示します。
- バックエンドからアップロード用の一時URL (`getUploadUrls`) を取得する際、追加でチェックに用いた期待するスキーマ文字列 (`csvHeader`) をリクエストに付与します。

### 2. バックエンド

バックエンドにCSVスキーマチェックの機能を追加する。
- Lambda API (`getUploadUrls`) にて、送られてきた `csvHeader` を検証します。
- バックエンド側であらかじめ定義されたスキーマ（84カラムのヘッダー文字列）と不一致の場合、HTTP 400 (Bad Request) を返し、ファイルのS3アップロードを拒否する二重のセキュリティチェックを実施します。
